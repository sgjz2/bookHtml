## 发布与维护

GitHub Pages 从 main 分支的仓库根目录发布，必须保留 .nojekyll。
修改在本地源项目维护，验证后同步静态产物，再提交到此仓库。
读者无需安装 Node，也不依赖外部 API。

知识星空的连线以原文证据为准；位置用于阅读编排，不表示因果或知识距离。同段共现默认关闭。
